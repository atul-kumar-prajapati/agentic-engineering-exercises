# Current AI-History Export Policy

Status: approved
Effective: 2026-07-15
Owner: Workspace Security

- A workspace is eligible only on the Enterprise plan.
- AI-history export is blocked when the workspace data-residency mode is `restricted`.
- The caller must have an active membership in that same workspace.
- The membership role must be `admin`.
- Billing-customer ownership does not grant workspace access.
- Suspended membership never grants access, including for a billing owner.
