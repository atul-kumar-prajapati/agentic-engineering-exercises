# Billing Service Ownership

Status: Current

| Area | Owner | Responsibility |
|---|---|---|
| Recognized-revenue formula | Billing Platform | Defines and changes calculation rules |
| Tenant-to-account directory | Billing Platform | Maintains billing-account boundaries |
| Revenue dashboard | Support Analytics | Consumes the shared summary |
| Scheduled finance snapshot | Finance Operations | Consumes the shared summary |

Consumer teams may report incidents but must not create separate revenue formulas.
