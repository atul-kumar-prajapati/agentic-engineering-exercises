# Graph Questions

Use the same questions before both implementation runs.

1. Which function calculates recognized revenue and which UI or job consumes it?
2. Where is a tenant mapped to its billing account?
3. Which source defines whether credits and refunds reduce the metric?
4. Which team owns the calculation and which team only consumes it?
5. Which stale document or inferred edge could send an agent to the wrong file?

For the graph-first run, record the exact `graphify query`, `graphify path`, or `graphify explain` command used for every answer. Mark important inferred or ambiguous edges as source verified only after opening the linked source.
