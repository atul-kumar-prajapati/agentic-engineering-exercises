# SLA Rollout Proposal

Status: Draft
Created: 2026-02-14
Last reviewed: 2026-03-02

This proposal was prepared for the first escalation pilot. It was not approved as the production policy.

## Proposed pilot behavior

- Escalate high-priority cases after 24 hours.
- Move automatically escalated cases to `Incident Desk`.
- Run the process only in the dashboard session.

The pilot did not define how manual escalations or later API fetches should behave. The approved policy replaced this proposal before the production rollout.
