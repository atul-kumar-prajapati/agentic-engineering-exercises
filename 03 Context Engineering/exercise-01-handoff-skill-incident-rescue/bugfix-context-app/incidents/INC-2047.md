# INC-2047: Automatic escalation regression

Status: Open
Severity: High
Opened: 2026-08-08

## Request

Complete the automatic escalation fix for at-risk cases. Use the current SLA rules, preserve existing ownership and manual escalation behaviour, and keep the queue totals and saved workflow state consistent.

## Reported behavior

- A case below the current SLA boundary is escalated.
- Automatically escalated cases are moved to another owner.
- The dashboard can show values that differ from the state returned by a later fetch.
- A previous agent marked the work complete after running only the generic repository check.

## Scope

The incident is limited to the automatic escalation policy and its workflow API integration. Existing manual actions, filtering, risk scoring, and public workflow API names must remain compatible.
