# Exercise Evaluation Rubrics

## Common 100-Point Structure

| Area | Points | Observable basis |
|---|---:|---|
| Correctness and working behavior | 30 | Required behavior works and seeded defects are addressed. |
| Requirement coverage | 25 | Every acceptance criterion is represented. |
| Verification and evidence | 20 | Commands and artifacts independently prove the claims. |
| Isolation and scope control | 15 | Changes stay within ownership boundaries and avoid unrelated work. |
| Reasoning and maintainability | 10 | Assumptions, trade-offs, and decisions are concise and traceable. |

A pass is 80 or more with every exercise-specific non-negotiable satisfied. A partial submission is 50 to 79 or has one remediable evidence gap. A fail is below 50, cannot run from a clean checkout, or misses a non-negotiable. Documentation volume earns no points unless it supplies required evidence.

## Agent Onboarding Kit

Non-negotiables: both runs use the same feature request and working conditions, the required onboarding and before-and-after evidence are present, the final Needs Attention behavior uses one source of business rules, existing filters still work, and the required checks pass.

## Agent Guardrails

Non-negotiables: both runs use the same agent conditions, the selected agent's native configuration invokes executable guardrails, normal development and the Release Readiness feature work, the restricted canary never reaches the guarded agent or evidence, indirect access probes fail, approval gates remain distinct, and the weakened-policy check fails as expected.

## Spec-Driven Feature Development

Non-negotiables: both agent runs use the same conditions and first attempt; three to five evidence-based clarifications distinguish confirmed decisions from assumptions; authorization, billing, pending changes, failure recovery, and scope are resolved; every requirement and acceptance criterion traces into the plan and tasks; the patches and comparison are genuine; no feature implementation or starter-input changes are included; all required checks pass.

## Superpowers Skill-Driven Development

Non-negotiables: both runs use the same conditions and first attempt; the recorded Superpowers workflow proceeds through approved design, plan, execution, test-driven development, review, and verification; design and plan artifacts are substantive; Red precedes production implementation and Green; both patches are genuine; the final interface uses the shared invitation service; permissions, policy, normalized duplicates, expiry, single-use transitions, and immutable rejection behavior pass the protected tests; all required checks pass.

## Handoff Skill Incident Rescue

Non-negotiables: both implementation runs use the same agent conditions, prompt, time limit, and first attempt; the baseline receives the raw session history while the final agent receives only the unedited generated handoff and its referenced repository files; the handoff stays within 1,200 words and separates authoritative requirements from the draft threshold, owner reassignment, irrelevant error, and unsupported completion claim; both patches and the source-backed audit are genuine; the final implementation uses the current 48-hour boundary, preserves owners and manual escalations, is idempotent, persists queue state, keeps totals consistent, and passes all required checks.

## Domain Modeling Product Rules Rescue

Non-negotiables: both first-attempt runs use the same conditions and exact product request; the final agent receives only `CONTEXT.md` and its referenced files; the skill output and audit separate billing customer, user, workspace, membership, role, and residency while ranking current and legacy sources; the decision record resolves the conflict; both patches are genuine; the final policy enforces Enterprise plan, standard residency, requesting-user identity, active same-workspace membership, and admin role while rejecting billing ownership alone; all eight protected checks pass.

## Graphify Billing Knowledge Graph

Non-negotiables: both first-attempt runs use the same conditions and incident request; a real Graphify JSON, HTML, and report cover the complete exercise; graph queries precede source inspection in the graph-first run and answer all six questions; the graph identifies the formula, account directory, dashboard, scheduled snapshot, current contract, stale sources, unrelated gross metric, and owner; important inferred or ambiguous edges are source verified; both patches and the graph audit are genuine; the final implementation handles charge credits, refunds, account grouping, and missing mappings while preserving inputs, gross volume, and both shared consumers; all eight protected checks pass.

## Playwright MCP Checkout Rescue

Non-negotiables: both first-attempt runs use the same conditions and exact request; the final run uses the official Playwright MCP against the live URL and records `browser_snapshot`, `browser_network_requests`, and `browser_network_request` evidence; fixed waits, generated-class selectors, skipped tests, and serial-only execution are absent; every test uses a unique server session; tax and authorization bodies are asserted; approval and decline are independent; retry sends a new authorization; duplicate submission sends exactly one authorization; the application and API fixture remain unchanged; the twenty-repeat two-worker run exits zero; a genuine trace remains below 10 MB.

## TDD Skill Network Boundary Rescue

Non-negotiables: two first-attempt runs use the same conditions and exact request with the TDD skill as the only changed input; skill provenance identifies the upstream source, commit, installed path, and hash; loading, filtered-empty, and retry each show a test-only red failure before the smallest green change; success, server-empty, and request error are independently covered; all tests exercise `GET /api/cases` through MSW and user-visible queries; mocked `fetch`, component internals, horizontal test batches, unhandled-request warnings, and leaking handlers are absent; filtering makes no new request; Retry sends exactly one new request and recovers; all three shuffled-order runs pass.

## Verification Skill Workflow Gate

Non-negotiables: the old claim is correctly limited; one fresh command stops on failures and runs client release tests, client build checks, and the full Maven suite; missing `decisionState` and unknown transitions are rejected; final evidence includes the exact command, output, and exit code.

## Progressive Disclosure Release Skill

Non-negotiables: the package follows Agent Skills metadata and structure; `SKILL.md` stays focused and routes to references and a deterministic Git helper; evals include negative boundaries; both first-attempt outputs are comparable; final notes use the real Git range, trace published items, flag breaking and missing evidence, and exclude internal work.

## Skill Trigger Boundary Evals

Non-negotiables: the real `change-review` description is evaluated on 20 protected substantive positive and negative requests; every request has three model decisions before and after; held-out score improves to at least 75 percent; the description includes clear use and non-use boundaries without held-out phrase leakage.

## Skill Benchmark and Package Gate

Non-negotiables: all four train and held-out tasks have three baseline and three with-skill runs; assertion grades have evidence plus model, token, and time metrics; held-out quality improves with no critical regression; variance and cost are reported; the installable `.skill` archive contains the exact evaluated skill and no expected-answer leakage.

## Parallel Worktree Conflict Rescue

Non-negotiables: all three fixed lanes start from one base SHA, preserve inspectable commits and complete handoffs, remain inside path ownership, request shared types without editing them, and pass lane and integrated checks; only the integration owner changes the shared file.

## Specialist Review Merge Gate

Non-negotiables: four specialists review the same SHA with evidence-backed findings; security covers dynamic HTML and the service authorization boundary; accessibility includes keyboard evidence; performance uses comparable measurements; every finding is triaged; affected specialists recheck the final SHA.

## Agent Kanban Collision Control

Non-negotiables: every card satisfies the schema, unclear and colliding work remains blocked, cancelled work retains its reason and history, one ready lane has an inspectable commit and review decision, and board, ownership, application data, and integration log agree.

## Implementation-Backed Workflow Reconstruction

Non-negotiables: renderable state and sequence diagrams show normal and high-risk approval, security review, provisioning failure, rollback request, and rollback completion; every non-obvious edge maps to current source; contradictions with the protected legacy description are explicit.

## Graph-Backed Notification Fallback Rescue

Non-negotiables: real graph output and scoped commands identify routing, provider, consent, email, and queue dependencies; inferred edges are source checked; diagrams match code; protected tests prove push, consented SMS, email fallback, and durable queue behavior.

## Payment Retry Visualization and Fix

Non-negotiables: four source diagrams cover architecture, state/process, interactions, and data; invalid signatures and unknown references fail; duplicate captured events are idempotent; ledger and receipt relationships trace to source and tests.

## Failure-Preserving PR Evidence Pack

Non-negotiables: the workflow uses least privilege and stable paths, binds evidence to commit SHA, uploads on failure without masking it, preserves command exit codes, records artifact digests, and includes risk, reviewer action, and rollback.

## Feature Flag Kill-Switch Proof

Non-negotiables: enabled, disabled, provider-error, and rollback states are tested; disabled and error states make no preview API call or preview telemetry; targeting is stable; the rollback drill contains observed timing and results.

## Performance and Accessibility Release Gate

Non-negotiables: evidence comes from the same commit, URL, and environment with at least three Lighthouse runs; performance is at least 0.90, accessibility is 1.00, LCP is at most 2500 ms, automated accessibility violations are zero, and threshold failures return non-zero.

## Security and Accessibility Review Gauntlet

Non-negotiables: the real patch applies, scanner true and false positives are distinguished, the manual behavior bug is found, the server boundary is protected, and confirmed issues receive regression tests.

## Independent Diff Triage

Non-negotiables: the exact bundled range is reviewed, real blockers are evidenced, the seeded unsupported claim is explicitly confirmed or dismissed, and blocker fixes pass verification.

## Code Review Regression Gate

Non-negotiables: the real review model is sampled, multi-bug recall and clean-control precision meet thresholds, the provider does not encode answers, and model/configuration/sample count/limitations are reported.

## Progressive Context Budget Refactor

Non-negotiables: repository rules are always selected, current authoritative task sources are preferred, stale and irrelevant sources are excluded, reported bytes equal selected bytes, the maximum budget is enforced deterministically, and correctness is not reduced to save context.

## Risk-Based Model Routing Cost Gate

Non-negotiables: low-risk work can use the fast tier, bounded work can use balanced, high-risk work uses reasoning, high-ambiguity work clarifies before execution, every evaluated lane has three runs, and total cost includes retries and escalation while meeting quality floors.

## Minimal-Diff Scope Budget

Non-negotiables: only export moves to the design-system variant, checkout and destructive behavior remain legacy, the budget is declared before editing, actual scope stays at or below three files and 60 lines or has pre-change expansion evidence, and unrelated cleanup is absent.

## Characterization-First Rules Refactor

Non-negotiables: characterization tests and before output precede refactoring, all protected golden cases remain unchanged, public behavior rather than private helpers is asserted, suspected bugs are recorded but not silently fixed, and the final oracle passes.

## Strangler Checkout Route

Non-negotiables: one injectable router sends only card checkout to the new slice, gift-card and invoice remain legacy, public result fields remain stable, fallback respects external-side-effect safety, and the legacy path remains available for rollback.

## Contract-Safe Full-Stack Rules Extraction

Non-negotiables: a real `DecisionPolicy` owns validation while the service owns lookup and persistence; exact rejection message, JSON fields, and repository state are preserved; API and client checks both pass; before and after contract outputs match.

## Trace-Measured Session Waste Reduction

Non-negotiables: raw events remain unchanged, first reads and first failures are not counted as duplicate work, baseline metrics are derived, one durable improvement targets a measured root cause, the replay is comparable, preventable calls fall, and correctness remains verified.

## Repeated Mistake to Repository Rule

Non-negotiables: rules are supported by repeated corrections, `AGENTS.md` contains only safe-start guidance and routes to focused `.agent` detail, executable checks enforce stable IDs, canonical status, and injected time, and genuine same-condition first attempts show before-and-after behavior.

## Trace-Backed Workflow Optimizer

Non-negotiables: all eight protected cases have three baseline and three candidate runs with model, tokens, time, and evidence-backed assertion grades; held-out quality improves; no critical assertion fails; instructions contain no case-answer leakage; adoption reports variance and context cost.
