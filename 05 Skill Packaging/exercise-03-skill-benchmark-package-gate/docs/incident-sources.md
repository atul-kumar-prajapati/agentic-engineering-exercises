# Incident Source Rules

- Use only supplied timelines, impact records, remediation diffs, and follow-up records.
- Separate confirmed facts from inference.
- Cite the source identifier for timeline, impact, cause, and remediation claims.
- Do not claim recovery before the final healthy signal.
- Do not turn a proposed follow-up into completed work.
- State uncertainty when sources conflict.

The current skill sounds polished but does not reliably enforce these rules.
