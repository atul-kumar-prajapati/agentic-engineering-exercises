# Skill Comparison Evidence

Record the following in both `before.md` and `after.md`:

- Agent
- Model
- Tools and permissions
- Time limit
- Exact release request
- Attempt number
- Skill enabled or disabled
- Input files provided
- Output file
- Verification result and exit code

Use first attempts and the same conditions. The before run uses the raw prompt and source inputs. The after run uses the packaged skill and the same source inputs.
